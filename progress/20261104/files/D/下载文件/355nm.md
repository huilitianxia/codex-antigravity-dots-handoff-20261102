# 桌面级 355nm 紫外激光雕刻机（UV Galvo Laser）出海众筹项目迁移文档

> **文档用途**：本文档用于将当前项目的商业背景、软硬件技术选型、Web 预热站架构规范、供应商评估结论及待办事项无缝迁移至 **Antigravity** 开发环境中继续推进。

## 一、 项目背景与商业定位 (Project Background)

1. **业务转型背景**：
   * 团队由传统外贸纸品文具（Sticky Notes）向高附加值硬科技制造转型，此项目为家族业务翻盘的核心战略级项目，资金与时间容错率极低，必须遵循**“单点突破、砍掉冗余支线、确保首战回血”**的原则。
2. **产品核心规格**：
   * **机器类型**：桌面级高速振镜激光打标/雕刻机（Galvo Laser System），单次标准幅面 `110mm x 110mm`（支持扩展）。
   * **核心光源**：**355nm 5W 紫外激光（UV Laser）**，主打“冷加工”特性（通吃玻璃、水晶内雕、塑料高反材料打标不变色不烧焦、PCB 微加工、非金属与金属精细打标）。
   * **对标竞品**：直接对标行业旗舰机型（如 **xTool F1 Ultra / F2 Ultra** 级别）。
   * **终端客单价区间**：高客单价定位（预计 **$2,500 – $3,500+ USD**）。
3. **核心目标市场与受众画像**：
   * **首发渠道**：预计 **12月** 登陆美国众筹平台（**Kickstarter** 为主，Indiegogo 为辅）。
   * **核心受众**：欧美 **Prosumer（专业消费者）**、Etsy 个性化定制店主、小型手作工坊主、资深硬件创客（Maker）。
   * **用户心智特征**：由于机器单价高达数千美金，纯新手小白占比极低（<10%）。目标买家高度看重**底层工业级稳定性、矢量路径精度、跨平台工作流兼容性（尤其是 macOS 与 LightBurn）**以及安全合规性。

## 二、 软硬件架构设计与技术选型决策 (Architecture & Technical Decisions)

### 1. 核心控制板卡与上位机生态对比决策
目前团队已采购两家供应商的控制卡进行样机同台实测，技术底牌与选型倾向如下：

| 维度 | **方案 A：长沙八思量 (BSL / SeaCAD 方案)【主推/核心方案】** | **方案 B：北京尤米纳 (闻士云 / 伍韦怡 "伍博" UMNic-v10)【存疑/待实测淘汰】** |
| :--- | :--- | :--- |
| **底层属性** | 国内工业级激光振镜控制卡头部正规军，工程团队此前一直使用，稳定性已验证。 | 0-20人小微团队（原做景区水晶内雕），底层为“打印机式光栅扫描系统”而非标准雕刻机系统。 |
| **LightBurn 兼容性** | **100% 原生支持**。LightBurn 1.7.00+ 官方底层内置 `BSLFiber (Galvo)` 协议与专属 Logo。 | **完全不兼容**。封闭系统，无法直连 LightBurn，仅能通过自有上位机操作。 |
| **核心卖点/噱头** | 工业级微秒级振镜控制、矢量/位图全能、支持旋转轴、无缝接入全球创客标准生态。 | 主打后台接入 AI 图源大模型（照片一键转 2.5D/3D 伪浮雕灰度图），概念偏向景区自助速雕。 |
| **BOM 成本差异** | 行业标准工业卡良心价（基准价）。 | **单卡报价贵出 $200 USD（约 1400+ RMB）**，存在严重的价格倒挂与智商税嫌疑。 |
| **战略定性** | **12月美国众筹唯一主力方案**。直接将 `Native LightBurn 1.7 Galvo Support` 作为核心头牌卖点。 | **高危风险项**。已购入 1 张卡做盲测对比；若实测无 50% 以上肉眼级碾压优势，立即放弃批量采购。 |

### 2. 双轨交互控制逻辑（Dual-Control Workflow）
采用行业主流高端机型的**“机身触控屏 + PC 端 LightBurn”**双轨互补架构：
* **PC 端（LightBurn 1.7+ / SeaCAD）**：通过 USB / 局域网连接，负责复杂矢量排版、多层参数（速度/功率/频率 kHz）精细设定、实时联机控制。
* **机身自带触控屏（Offline Standalone）**：负责读取 U盘/TF卡导出文件进行脱机雕刻、物理控制激光头归零（Homing）、红光走边框预览（Framing）、急停与功率微调。

### 3. Web 营销与众筹预热落地页架构 (`huilitianxia/-web-design-ops`)
当前由 Codex 跟进开发的 Web 端项目，在 Antigravity 中需严格遵循以下转化导向架构规范：
* **技术栈与性能硬指标**：
  * 采用轻量级静态生成架构（SSG，推荐 Astro / Next.js Static Export / Vite），**移动端首屏加载时间必须 < 1.5s**，严禁厚重的客户端水合阻塞首屏。
  * 媒体资源优化：激光雕刻过程动效严禁使用大体积 `.gif`，统一压制为静音循环播放的 `WebM / MP4`（控制在数百 KB 内）或 `WebP / AVIF`。
* **核心转化漏斗（Pre-launch Funnel）**：
  * **Step 1（Lead Capture）**：首屏 Above-the-Fold 必须包含高对比度 Email 收集框，锁定超早鸟优惠（Super Early Bird 40%-50% OFF）。
  * **Step 2（VIP Deposit 锁客）**：集成 **Stripe / PayPal $1（或 $5）VIP 意向金极速结账流**（支持 Apple Pay / Google Pay 一键支付），提升开局前 48 小时转化率（目标锁定 500-1000 名付费 VIP）。
  * **Step 3（归因与自动化）**：前端表单与支付回调必须完整保留 `UTM` 参数（区分 Meta Ads / Google / YouTube KOL 流量），并通过 Webhook 实时同步至邮件营销系统（Klaviyo / Mailchimp）。

## 三、 关键配置与连接规范 (Key Configurations)

### 1. 八思量 (BSL) 接入 LightBurn 1.7.00+ 标准配置流
在编写产品说明书、FAQ 页面及录制演示视频时，需严格按以下官方链路展示：
1. **软件版本要求**：必须使用 **LightBurn v1.7.00** 及以上版本（需搭载 Galvo 振镜许可支持）。
2. **协议识别与配置导入**：
   * 硬件通过 USB 连接电脑 -> 打开 LightBurn 点击 `Devices（设备）` -> `Find My Laser（查找我的激光器）`。
   * 识别设备类型为：`BSLFiber (110mm x 110mm) | Type: (Galvo) | Connection: None`。
   * **关键步骤（导入出厂校准参数）**：在向导界面点击 `Import SEACad Config`，导航至出厂配置目录，导入 **`BslCAD.cfg`** 或 **`LmcPar.cfg`** 配置文件（确保振镜场镜畸变校正、延时参数与红光偏置准确无误）。
   * 设定工作区尺寸：`X: 110mm, Y: 110mm`，原点位置：`Front Left（前侧左侧）`。

### 2. 光学安全遮光罩（Enclosure）选型硬指标
* 针对 **355nm 紫外激光（UV-A 波段）**，遮光罩板材（高分子防紫外 PC / 亚克力）必须向供应商索取 **355nm 波段的 OD 值（Optical Density 光密度）检测报告**。
* **安全阈值**：必须达到 **OD4+ 至 OD6+**（阻隔 99.99% 以上的 355nm 散射辐射），且需验证长时间紫外照射下的**抗老化、防发黄脆化**性能，满足美国 **Class 1 激光安全标准**。

## 四、 当前遇到的具体问题与风险点 (Current Issues & Blockers)

1. **硬件工程样机组装与遮光罩定型问题**：
   * 目前样机在机械组装上仍有少量细节待排障，遮光罩的具体材料与色号（Pantone 色号及防紫外板材）正在最终确认中。
2. **供应商“AI 伪 3D 效果图”认知偏差（待盲测证伪）**：
   * 北京尤米纳（伍博）提供的瑞兽麒麟样品图实为 **Midjourney 生成的高对比度 AI 素描灰度图 + 黑色涂层导光板 + 底部暖光 LED 灯带** 的视觉作弊效果，且其样品底部存在明显的竖向扫描拼接条纹瑕疵。
   * 需通过实机盲测，向决策层彻底证伪“多花 $200 美金买封闭打印机板卡”的伪需求，砍掉不切实际的“国内景区高价速雕机”支线幻想。
3. **12月众筹宣发窗口期极度紧迫（广告竞价飙升）**：
   * 11月至12月正值欧美黑五网一（BFCM）与圣诞广告竞价最高峰，若无前期邮箱与 VIP 蓄水池，12月裸上众筹将面临极高的买量成本与冷启动失败风险。
4. **产品测评视频与真实度危机**：
   * 计划由自有团队拍摄介绍视频，存在“过度包装成官方宣传片、缺乏欧美极客信任的实操镜头”的风险。
