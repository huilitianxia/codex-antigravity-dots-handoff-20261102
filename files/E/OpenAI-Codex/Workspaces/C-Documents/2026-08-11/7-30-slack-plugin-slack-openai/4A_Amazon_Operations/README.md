# 4A Amazon Operations

本目录是当前 Codex 项目的唯一业务主线：4A Limited 的亚马逊电商经营。

## 目录

- `source_workbooks/`：当前运营总表、VC/SL 跟卖检测与分类、缺货评分，以及 2023 历史总表。
- `workbuddy_artifacts/`：从 WorkBuddy 复制的 3M 对标、搜索词/竞品汇总、产品匹配、缺货筛选、补货清单与配套脚本。
- `workbuddy_task_records/`：跟卖检测任务记录。
- `PROJECT_MEMORY.md`：经筛选后的亚马逊运营记忆与后续判断规则。
- `PRICING_AND_BULK_UPLOAD.md`：批量改价、参考价、折扣价与安全上线流程。

## 范围约束

本目录不纳入网站、电脑维护、视频制作、定时简报等其他 WorkBuddy/Codex 内容。迁移采取复制方式，D 盘和 E 盘源文件未删除、未覆盖。

## 当前权威源

1. 商品、SKU、VC/SL ASIN 与价格：`source_workbooks/亚马逊供应商和开店总表-2026 (1).xlsx`
2. 现有 ASIN 跟卖候选分类：`source_workbooks/4A_跟卖分类整理_2026-08-11.xlsx`
3. 实际上架权限、当前售价、库存和报错：以 Seller Central 实时页面和最新官方报告为准。
